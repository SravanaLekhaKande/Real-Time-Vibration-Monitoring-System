# Vibration Monitoring System (Demo)
This simple Python app simulates real-time vibration data from four accelerometers, updates time/FFT plots, and issues alerts via a PyQt5 GUI.

## How To Run
- Install dependencies: `pip install pyqt5 matplotlib numpy`
- Run: `python main.py`

## Project Structure
- main.py: Launches the app
- simulation.py: Simulates sensor data
- signal_processing.py: Signal processing helpers
- config.py: System config
- gui.py: GUI and logic
